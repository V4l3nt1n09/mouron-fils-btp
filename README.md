# 🏗️ MOURON & FILS — Application de gestion BTP

Application web de gestion pour la **SARL Mouron & Fils**, entreprise familiale du BTP en Ariège.

## ✨ Fonctionnalités

- 📅 Planning et calendrier des interventions
- 🏗️ Gestion des chantiers (création, suivi, statuts)
- 👥 Gestion des clients
- 👷 Gestion d'équipes (24 membres, 7 rôles)
- 📝 Rapports d'intervention avec signature digitale
- ⏱️ Feuilles d'heures
- 💬 Messagerie interne hiérarchique
- 📎 Documents Interfast (devis liés aux chantiers)
- 💾 Sauvegarde locale + synchronisation cloud

## 🛠️ Stack technique

- HTML / CSS / JavaScript (vanilla)
- [Supabase](https://supabase.com) (base de données + authentification)
- [GitHub Pages](https://pages.github.com) (hébergement HTTPS)
